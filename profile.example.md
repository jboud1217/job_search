# Candidate profile

This is the background Claude scores each role against. Copy this file to
`profile.md` (which is gitignored) and edit it freely — the more specific and
honest it is (level, must-haves, dealbreakers), the better the scoring. Keep it
concise; a few hundred words is plenty.

In GitHub Actions, the workflow writes `profile.md` from the `PROFILE_MD`
repository secret, so your real profile never has to be committed.

## Current role & background
- Seniority, domain, and years of experience.
- Core technical strengths (cloud, languages, tooling).
- Location.

## Target roles
- Titles you want (e.g. Forward Deployed Engineer, Solutions Architect).

## Strengths to weight highly
- What makes you a strong fit; portfolio proof points.

## Preferences & constraints
- Location / remote / relocation preferences.
- Target seniority; roles to score down.
- Compensation expectations relative to your current level.

## Dealbreakers (score these low)
- Role types you don't want.
